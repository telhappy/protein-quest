# protein-quest

A Godot 4 game where you explore a 3D protein surface mesh (1ATP) and try
to find its binding site.

Play it at: https://telhappy.github.io/protein-quest/

## Project layout

- `scenes/`, `scripts/` — the Godot game.
- `assets/` — protein meshes and binding-site data generated by the
  pipeline (see `pipeline/README.md`).
- `pipeline/` — Python pipeline that converts a PDB structure into the
  glTF mesh + binding-site JSON used by the game.

## Deploying the web build

The game is exported to WebAssembly and served from the `gh-pages` branch
via GitHub Pages.

```bash
./deploy_web.sh
```

This re-exports the Godot project for Web (`godot --headless --export-release
"Web" web/index.html`) and force-pushes the result to `gh-pages`. GitHub
Pages picks up the change within a minute or two.

Requires the Godot editor and its Web export templates installed locally
(set `GODOT_BIN` if Godot isn't at the default macOS path).
